# Nginx 版本更新总览

本节持续追踪 Nginx 的版本发布动态、主线版与稳定版的演进以及配置兼容性变更，帮助运维和开发团队及时掌握上游更新方向，合理规划升级策略。

## 版本分支

Nginx 采用**主线版（Mainline）**和**稳定版（Stable）**双分支发布模式：

| 分支 | 说明 |
|------|------|
| **Mainline** | 最新功能与修复的活跃开发分支，包含所有新特性和改进，版本号为奇数次版本（如 1.27.x） |
| **Stable** | 经过社区验证的生产就绪分支，仅接收关键 bug 修复和安全补丁，版本号为偶数次版本（如 1.26.x） |

> 建议生产环境优先使用 Stable 分支以获得更高的稳定性保障；需要新特性或上游最新修复时可选用 Mainline 分支。

## 发布节奏

Nginx 社区通常按以下节奏发布版本：

- **Mainline**：不定期发布，持续引入新功能和优化
- **Stable**：通常在 Mainline 分支稳定后，每年发布一次新的 Stable 版本
- **Patch**：按需发布，主要修复安全漏洞和关键回归问题
