# Kubernetes 1.32 更新

- **发布日期**：2024 年 12 月 11 日
- **主题 / 代号**：Penelope
- **版本类型**：Minor 版本（GA）

## 重要新特性

Kubernetes 1.32 带来了多项面向调度、资源管理和安全性的增强：

1. **QueueingHint 进入 Beta（调度框架）**
   调度器新增 QueueingHint 机制，允许调度插件在 Pod 进入调度队列时提供提示，显著减少不必要的重调度计算，提升大规模集群下的调度吞吐。

2. **动态资源分配（DRA）支持设备健康监控**
   DRA 框架扩展了设备健康状态感知能力，集群可以根据 GPU、FPGA 等设备的实时健康情况动态调整资源分配策略。

3. **容器镜像签名验证与策略控制**
   引入了对镜像签名的原生策略支持，配合准入控制器可在容器运行时之外完成镜像来源和完整性校验。

4. **用户命名空间（User Namespaces）支持 Pod 级别启用**
   此前仅在容器级别支持的用户命名隔离能力，现可在 Pod 规格中统一启用，进一步降低容器逃逸风险。

5. **存储容量跟踪改进**
   CSIDriver 的存储容量跟踪能力得到增强，调度器在绑定 PVC 时可更精确地预判节点存储资源，减少调度失败重试。

## 废弃的 API / 功能

以下 API 版本或功能在 1.32 中已被标记为废弃，将在未来版本移除：

| 资源 | 废弃的 API 版本 | 替代方案 | 预计移除版本 |
|------|----------------|---------|-------------|
| FlowSchema | flowcontrol.apiserver.k8s.io/v1beta3 | flowcontrol.apiserver.k8s.io/v1 | v1.35 |
| PriorityLevelConfiguration | flowcontrol.apiserver.k8s.io/v1beta3 | flowcontrol.apiserver.k8s.io/v1 | v1.35 |
| Node 生命周期控制器中的 `--pod-eviction-timeout` | 命令行参数 | 使用 Taint 与 Toleration 机制 | v1.34 |
| `kube-proxy` 的 `--healthz-bind-address` | IPv4 0.0.0.0 默认值 | 显式指定监听地址 | v1.34 |
| 旧版 NodeLease 心跳模式 | 直接写 Node Status | 统一使用 Lease 对象 | v1.33 |

## 升级注意事项

1. **API 迁移优先**：若集群中仍存在使用 `flowcontrol.apiserver.k8s.io/v1beta3` 的自定义 FlowSchema 或 PriorityLevelConfiguration，请在升级前将其迁移至 `v1` 版本。

2. **准入控制器检查**：如启用了镜像签名验证相关准入插件，升级后需确认 `ValidatingAdmissionPolicy` 或对应 Webhook 配置兼容新的镜像引用格式。

3. **调度器性能监控**：QueueingHint 默认在 Beta 阶段启用，建议在升级后通过 `scheduler_pending_pods` 等指标观察调度延迟变化。

4. **存储插件兼容性**：使用 CSI 驱动的集群应确认驱动版本 >= 1.12，以充分利用存储容量跟踪改进。
