# 全文搜索实现原理

搜索是文档站点的核心功能。在 DocME 中，我们选择了 **Orama** 作为全文搜索引擎，为你提供毫秒级的搜索体验。

## 为什么选择 Orama？

Orama 是一个现代化的全文搜索引擎，具有以下优势：

- **极速**：基于内存的倒排索引，查询延迟低于 1ms
- **轻量**：核心库仅几十 KB
- **类型安全**：完全基于 TypeScript
- **灵活**：支持自定义分词和排名算法

## 索引构建

在构建时，DocME 会遍历所有文档页面，提取标题和内容：

```ts
import { createFromSource } from 'fumadocs-core/search/server';

export const { staticGET: GET } = createFromSource(source, {
  language: 'chinese',
});
```

## 搜索接口

前端搜索组件使用 Orama 的客户端 API：

```ts
const results = await search(db, {
  term: query,
  limit: 10,
});
```

## 中文支持

对于中文内容，Orama 默认使用字符级分词。你也可以集成 jieba 等中文分词库获得更好的效果。

## 性能优化

- 索引在构建时预生成，无需运行时计算
- 支持增量更新，新内容无需重建全部索引
- 客户端缓存常用查询结果

## 总结

Orama 为 DocME 提供了强大的搜索能力，同时保持了极小的体积和出色的性能。我们强烈推荐在你的文档项目中使用它！
