# Bento 风格首页设计揭秘

在最新版本的 DocME 中，我们引入了全新的 **Bento 风格首页设计**。这种设计灵感来源于日本的便当盒，强调模块化、信息密度和视觉层次。

## 什么是 Bento 风格？

Bento 风格（便当盒风格）是一种网格化布局设计，特点包括：

- **模块化卡片**：每个功能区域都是一个独立的卡片
- **不对称网格**：不同大小的卡片创造视觉节奏
- **信息密度**：在有限空间内展示丰富内容
- **清晰层次**：通过大小和颜色区分重要性

## 设计实现

我们的 Bento 首页使用了 CSS Grid 实现灵活布局：

```tsx
<div className="grid grid-cols-1 md:grid-cols-3 gap-4">
  <Card className="md:col-span-2">主要功能</Card>
  <Card>统计数据</Card>
  <Card>终端展示</Card>
  <Card className="md:col-span-2">框架支持</Card>
</div>
```

## 响应式策略

- **移动端**：单列堆叠，确保可读性
- **平板**：双列网格，平衡内容密度
- **桌面**：三列网格，完整 Bento 体验
