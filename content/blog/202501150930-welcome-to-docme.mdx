# 欢迎使用 DocME

DocME 是一个基于 **Next.js** 和 **Fumadocs** 的现代化文档站点构建工具。它让创建美观、交互丰富的文档变得前所未有的简单。

## 为什么选择 DocME？

- **极速构建**：基于 Next.js App Router 和 Turbopack
- **美观默认**：内置精心设计的 UI 组件和主题
- **MDX 支持**：在文档中直接使用 React 组件
- **全文搜索**：集成 Orama 搜索引擎

## 快速开始

```bash
npx create-docme-app@latest
```

只需一行命令，即可初始化你的文档站点。

## 核心特性

DocME 提供了丰富的功能来帮助你构建出色的文档：

- **自动导航**：基于文件结构自动生成侧边栏导航
- **代码高亮**：内置 Shiki 代码高亮支持
- **响应式设计**：完美适配桌面和移动设备
- **暗黑模式**：内置主题切换支持
