## DevSecOps 的定义

DevSecOps 是“开发（Development）、安全（Security）和运维（Operations）的缩写”。它是一种将安全性融入软件开发生命周期（SDLC）的全过程文化、自动化方法和平台设计方案。

其核心时将安全性视为软件开发生命周期中每一个成员的“共同责任”，而非仅仅是交付前的最后检查环节。

### 核心定义与关键要素

1. “安全左移”（Shift Left Security）：
    - 将安全测试和安全合规检查从开发周期的“最后环节”移动到“最初环节”。
    - 在编码、构建和测试的每个阶段即时识别和修复漏洞，从而大大降低由于安全问题导致的修复成本和风险。
2. 安全自动化：
    - 利用自动化的安全工具将安全分析、漏洞扫描和合规性检查嵌入到 CI/CD（持续集成/持续部署）流水线中。
3. 文化与协作：
    - 打破开发、安全和运维团队之间的“孤岛”，建立联合、共享责任的团队协作模式。
4. 宗旨：
    - 在实现软件快速、频繁交付的同时，确保交付内容的安全性、高质量和稳健性
