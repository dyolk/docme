### 安装 k8s 所需依赖 [step]

#### 安装 containerd [step]

1. 将下载好的 `containerd-2.1.8-linux-amd64.tar.gz` 文件上传至各个服务器的 `/usr/local/src` 目录下。
2. 执行如下命令解压文件至特定位置
    ```bash
    tar Czxvf /usr/local containerd-2.1.8-linux-amd64.tar.gz
    ```
