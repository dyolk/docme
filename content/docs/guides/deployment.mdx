## 静态部署

DocME 使用 Next.js 静态导出，生成纯 HTML/CSS/JS 文件。

### 构建

```bash
pnpm build
```

### 部署到 Nginx

将 `out/` 目录内容部署到任何静态文件服务器。

```nginx
server {
    listen 80;
    server_name doc.dyolk.com;
    root /var/www/docme/out;
    index index.html;

    location / {
        try_files $uri $uri.html $uri/ =404;
    }
}
```
